# Sistema de Gestão de Funcionários e Obras

Sistema desenvolvido em Python com integração ao MySQL para auxiliar no gerenciamento de funcionários, obras e seus respectivos históricos.

O projeto tem como objetivo aplicar conceitos de programação orientada a objetos, manipulação de banco de dados e organização de código em uma aplicação prática.

## 🚀 Tecnologias utilizadas

- Python
- MySQL
- mysql-connector-python
- python-dotenv
- Git e GitHub

## ⚙️ Funcionalidades

### Funcionários
- Cadastro de funcionários.
- Validação de CPF.
- Consulta de funcionários.
- Edição de informações.
- Desativação de funcionários.

### Obras
- Cadastro e gerenciamento de obras.
- Consulta e alteração de obras.
- Controle de status das obras.

### Histórico de obras
- Vinculação de funcionários a obras.
- Alteração de vínculo entre obras.
- Desvinculação de funcionários.
- Registro do histórico de vínculos.

## 🗄️ Banco de dados

O sistema utiliza MySQL para armazenar os dados de funcionários, obras e históricos.

As credenciais de conexão são configuradas por meio de variáveis de ambiente, utilizando o arquivo `.env`.
